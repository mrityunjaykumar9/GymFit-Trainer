HOW TO ADD AN EXERCISE VIDEO (only if you don't use exercise_photos instead)
=============================================================================

Only checked if no matching folder exists under ../exercise_photos/ for that exercise -
photos take priority since they're much smaller. Use this only if you specifically want
video for a particular exercise.

Drop a single video file here named after the exercise, using the same slug rule as
exercise_photos:

  "Barbell Bench Press" -> exercise_videos/barbell_bench_press.mp4
  "Push Ups"             -> exercise_videos/push_ups.mp4

Keep it short and small - a few seconds, low resolution (e.g. 480p), muted, no audio
track. Every video bundled here adds directly to the installed app size for every user,
regardless of device, so treat this as the exception rather than the default for the
whole exercise library.
